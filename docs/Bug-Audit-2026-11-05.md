# Bug audit: NH Combat Test (2026-11-05)

Owner: "let's completely audit and bugfix the "NH Combat Test" game for ALL BUGS."

## How it was done
- **Play-tests** (slot 4 "Testy", `NHTestNoMenuKeys` on, both restored after): boot, entering school, a fast-forwarded
  school day (2 real s per game hour), and the test bridge's state and action hooks for attendance, discipline, classes,
  social, quests, cliques, report cards, fortune, Lost & Found, the notice board, substitutes, schedules, sports
  (basketball, soccer, football), dialogue, pranks and AI. Console read on both the server and the client
  (`LogService` history).
- **Code read:** every first-party script (376 scripts plus 23 first-party packages, 3.7 MB) was dumped byte-exact and
  read line by line by 14 reviewers split by system, each cross-checking callers in the rest of the code. A scanner then
  looked for the "local used before it is declared" pattern across the whole codebase (2 real hits, both fixed).
- **Asset scan:** every Sound, Decal, Texture, image, mesh, SurfaceAppearance, Sky, Animation and particle in the place
  (146,216 instances) checked against the failed asset loads in the console.
- **Fixes in small batches.** Each script was backed up first (`ServerStorage.NH_Backup.Audit_pre`, one copy per script,
  named by its path) and only installed if it still matched the audited source, so no other session's edit was
  overwritten. Every changed line is marked `-- (audit)` in the source.
