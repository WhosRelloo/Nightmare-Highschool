# Stair stone block fix (1.50.2)

**Nightmare Highschool dev update, 2026-11-05**

- **The stair stone block now really matches the stairs.** It was a shade too bright, because its texture was much crisper than the stairs' own. It now has the same soft grain and the same shade, so a wall of blocks runs into a staircase with no visible change in the stone.
