# The new combat is on the main map (2.14.1)

**Nightmare Highschool dev update, 2026-11-13**

Everything from the combat test place is now on the main map:
- **Snappier fists:** swings start the instant you click, and hits land where you saw them.
- **Fist moves:** string enders, the clinch, riposte, lock-on, the delay string, the charged heavy and wall splats,
  with their new animations.
- **Fist growth:** hand gear at the armoury, race-flavoured finishers, and the Heat meter with EX skills.
