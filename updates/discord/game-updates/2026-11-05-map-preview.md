# Behind the scenes: the game meets the map (1.54.0)

**Nightmare Highschool dev update, 2026-11-05**

- **The real map now plays like the game.** Our builder's school map can now be walked with the game's own movement, camera and combat, so we can feel how everything fits before it all comes together.
- **What you'll be able to do there:** sprint and dash through the halls, slide, vault, jump with the new animations, fight, and watch the school go from day to a moonlit night.
- **Cinematic mode works there too**, so we can line up shots of the map as it's being built.
- **Nothing is saved there:** it's a preview space, so your real progress is never touched.
- More of the game will follow once the map is ready.
