# Accessories (Kit A / Kit B): install files

The 3D accessory kits (`docs/Accessories.md`). Everything here was installed into NH Combat Test by hand (Edit mode,
command bar or the Studio MCP); the Map place still needs it.

- `src/`: the modules as installed.
  - `Accessories.luau` -> `ReplicatedStorage.Config.Accessories`
  - `AccessoryWear.luau` -> `ReplicatedStorage.UI.AccessoryWear`
  - `AccessorySway.luau` -> `StarterPlayer.StarterPlayerScripts.Controllers.Character.AccessorySway`
  - `AccessoryFx.luau` -> `StarterPlayer.StarterPlayerScripts.Controllers.Character.AccessoryFx` (the copy here is
    newer than the place's: the grouped idle roles and NHPulse; reinstall it with the Kit B pieces)
  - `AccessoriesService.luau` -> `ServerScriptService.Services.Features.Accessories`
- `install/`: plain-text patches for existing modules; each matches its anchors once, backs the module up into
  `ServerStorage.NH_Backup.Accessories_pre` / `_pre2`, and refuses to run twice. Run in this order:
  `patch_identity`, `patch_appearance`, `patch_appearance2`, `patch_wardrobe`, `patch_wardrobe2`, `patch_enrollment`,
  `patch_enrollment2`, `patch_enrollment3`.
- `assemble_<batch>.luau`: builds `ReplicatedStorage.NHAccessories.<Item>` from the owner's import of
  `art/group-upload-accessories/<batch>/` (generated by `art/characters/accessories/acc_assemble.py`).
- `assemble_imported2a..d.luau` (1.86.0): batches 1-fix, 2-7 and Kit B in one pass (four parts: a script over about
  100 KB doesn't get through to Studio). Run from a file: Studio's MCP `execute_luau` with `studio_id` (the
  `rbxstudio` CLI can't pass one).
- `rebuild_bones_<item>.luau` (`art/characters/accessories/acc_rebuild_bones.py`): rebuilds a rigged piece's bones at
  the bind pose when a several-piece import left them on a separate part (the assembly reports it).
- `src/BodyFollow.luau` -> `StarterPlayer.StarterPlayerScripts.Controllers.Character.BodyFollow` (Kit C's skinned
  clothes follow the R6 limbs; `install/install_bodyfollow.luau`).
